# Fresnel 0.1.0 tester release

Fresnel is an experimental Mac-native harness for delegating bounded coding
components to Spark-X2.5-4B-MLX-8bit while a stronger orchestrator retains
planning, contracts, approvals, validation, and final review.

## Included

- Apple Silicon guided installer and hardware calibration
- versioned CLI/MCP orchestration protocol
- Codex, Cursor, OpenCode, and generic integrations
- local-first documentation and optional restricted Exa references
- macOS-sandboxed validation and target-restricted edits
- SQLite token, latency, cache, quality, approval, and failure metrics
- proposal-only self-improvement loop and shadow router

## Current benchmark

The included three-task regression suite passed 3/3. The older autonomous
baseline passed 1/3. This is a small directional benchmark, not a general model
capability score.

## Known limitations

- Apple Silicon only; 16 GB unified memory minimum, 24 GB recommended
- Spark-X2.5-4B-MLX-8bit is the only active worker
- long prompts did not show useful prompt-cache reuse under the tested 2 GB cap
- third-party tap/PyPI publishing is not yet configured
- tester build is not an Apple-signed `.pkg` or `.app`
