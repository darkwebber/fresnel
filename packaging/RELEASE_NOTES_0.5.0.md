# Fresnel 0.5.0

Fresnel 0.5 turns the local Spark worker into a recoverable Apple Silicon execution plane.

- Protocol 1.1 adds immutable charters, component risk envelopes, separate capability/edit/time budgets, checkpoints, context manifests, and result evidence while retaining protocol 1.0 compatibility.
- Runs live in durable Application Support workspaces. Atomic edits, idempotency records, APFS-friendly verified snapshots, stale-source checks, `run --resume`, `status --follow`, and checkpointed cancellation make interruption safe.
- Spark receives a compact worker kernel and discovers bounded repository, excerpt, local-doc, help, validation, environment, and authorized Exa capabilities only when required.
- Local memory now separates working state, event history, scoped facts, reversible playbooks, and expiring artifacts. Inferred personalization remains opt-in and requires three observations across two runs.
- The launchd socket-activated Swift supervisor loads Spark on demand, leases it across active runs, adapts to power/thermal/memory pressure, and unloads after 10 minutes on AC or 3 minutes on battery.
- A native Swift dashboard, richer progress events, MCP progress parity, resumable verified downloads, and a prebuilt runtime wheel improve installation and everyday observability.
- Self-improvement remains conservative: only reversible prompt/retrieval/playbook rules with passing shadow evidence and no permission expansion may activate, with instant rollback.

Spark-X2.5-4B-MLX-8bit remains the sole production worker. Routing to future models remains shadow-only.
