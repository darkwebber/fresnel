# Approval policy

This reference ships with Fresnel contract 0.4.2.

Fresnel auto-approves bounded read-only inspection, local documentation, help commands, validation, edits inside declared targets, and domain-restricted Exa lookup when the plan authorizes worker web research.

It denies secret access, path escape, contract modification, and changes outside declared targets. It escalates installs, deletion, deployment, pushing, external writes, and ambiguous actions. Store a user's choice with `fresnel approve REQUEST_ID approve|deny`, then rerun the same plan.
